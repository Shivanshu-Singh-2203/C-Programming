# C Programming Practice

A collection of **C (and some C++) programs** covering fundamental data structures, algorithms, file handling, strings, and mini-projects. Ideal for learning and practicing C programming concepts.

---

## Project Structure

```
Arrays           → Array problems and matrix operations
Binary Search Tree → BST implementation and tests
File Handling    → File I/O operations (copy, merge, compare)
Linked Lists     → Singly linked list operations
Mini-Projects    → Bigint, custom list, and matrix projects
Queues           → Queue implementations and tests
Stacks           → Stack implementations and tests
Strings          → String problems (palindrome, anagrams, duplicates)
```

---

## Features

- Modular code with `.c` and `.h` files  
- Makefiles included for easy compilation  
- Test programs included for most modules

---

## Compilation

With Makefile:

```bash
make
./program_name   # replace with actual executable
```

Without Makefile:

```bash
gcc filename.c -o output
./output
```
